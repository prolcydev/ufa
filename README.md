# UFA Forex

A React + Vite landing page for two UFA products:

- Forex Signals — TSh 60,000 per month
- Forex Ebook — TSh 70,000 one-time purchase

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The current version is a front-end design. Authentication, payments, subscriptions, signal delivery and ebook access will be connected in a later phase.
